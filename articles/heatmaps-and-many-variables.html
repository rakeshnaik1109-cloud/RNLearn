Heatmaps and Many Variables: Colour Scales, Correlation Matrices and Parallel Coordinates

A rainbow colour map that draws boundaries the data never had, a correlation matrix that hides three groups until you reorder it, and radar charts whose winner changes when you shuffle the spokes.

1. More Than Two Variables

A scatter plot shows two variables at once; real data often have dozens. A survey has many questions, a gene-expression study thousands of genes, a product catalogue many specifications. This part covers the plots designed for many variables: the heatmap, which turns a table into a grid of colours; the correlation matrix and the clustered heatmap; parallel coordinates; radar charts; and small multiples split by several variables at once.

Because several of these plots use colour to carry numbers, this part also explains how to choose a colour scale, one of the most consequential and most neglected decisions in data visualisation.

3. The Heatmap

A heatmap shows a table of numbers as a grid of coloured cells: rows and columns are two categories (days and hours, genes and samples), and the colour of each cell encodes its value. It shows overall patterns, such as daily rhythms, at a glance, but colour is a weak channel for exact values (Part 1), so heatmaps are for patterns, not precise reading. Adding the numbers as labels helps when the grid is small.

How to read a heatmap
  1. Read the colour bar first: which end is high, and is the scale linear or logarithmic?
  2. Check what the rows and columns are, and whether their order means something (time) or was chosen (clustering).
  3. Look for whole rows, columns or blocks that stand out, rather than single cells.
  4. Check whether values were standardised per row or column (Section 7).
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

rng = np.random.default_rng(0)
days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
hours = np.arange(24)
# synthetic web traffic: morning and evening peaks on weekdays, late mornings at weekends
base = np.array([[(30 + 60 * np.exp(-((h - 9) / 2.0) ** 2) + 80 * np.exp(-((h - 20) / 2.5) ** 2))
                  if d < 5 else (25 + 90 * np.exp(-((h - 12) / 3.5) ** 2)) for h in hours] for d in range(7)])
traffic = pd.DataFrame(base + rng.normal(0, 4, base.shape), index=days, columns=hours)

fig, ax = plt.subplots(figsize=(11, 3.6))
sns.heatmap(traffic, cmap="viridis", cbar_kws={"label": "visits per minute"}, ax=ax)
ax.set_xlabel("Hour of day")
ax.set_ylabel("")
ax.set_title("Website traffic by day and hour (sequential colour map)")
plt.tight_layout()
plt.show()

4. Choosing a Colour Scale

There are three kinds of colour scale, matching three kinds of data. [1]

  • Sequential: from light to dark (or dark to light) in one or two hues, for quantities that run from low to high, such as counts, temperatures or concentrations. Viridis, designed in 2015 by Stéfan van der Walt and Nathaniel Smith and now matplotlib’s default, changes evenly in perceived lightness, so equal data steps look equal, and it remains readable in greyscale and by most colour-blind people. [2]
  • Diverging: two contrasting hues meeting at a light neutral middle, for data with a meaningful centre, such as correlations (centred on 0), changes from a baseline, or deviations from a target.
  • Qualitative: distinct hues with no order, for categories (Part 1’s Okabe–Ito palette).

Avoid the old rainbow colour maps (“jet”), whose uneven brightness creates false boundaries and draws attention to arbitrary values. [3] And make sure a diverging scale is centred on the value that is meaningful, not on the middle of the data range.

5. Correlation Matrices

A correlation matrix shows the correlation (Part 6) between every pair of variables as a coloured cell, with a diverging colour map centred on zero. It is a quick map of which variables move together. Because it is symmetric, it is common to show only the lower triangle, and because the order of the variables is arbitrary, reordering them so that similar variables sit together can reveal hidden groups. [4]

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

rng = np.random.default_rng(1)
n = 300
f1, f2 = rng.normal(size=n), rng.normal(size=n)            # two hidden factors (synthetic)
df = pd.DataFrame({
    "sleep": f1 + rng.normal(0, 0.7, n),
    "mood": f1 + rng.normal(0, 0.8, n),
    "energy": f1 + rng.normal(0, 0.9, n),
    "screen_time": -0.6 * f1 + rng.normal(0, 1, n),
    "income": f2 + rng.normal(0, 0.7, n),
    "education": f2 + rng.normal(0, 0.8, n),
    "commute": 0.5 * f2 + rng.normal(0, 1, n),
})
corr = df.corr()

mask = np.triu(np.ones_like(corr, dtype=bool))            # hide the redundant upper triangle
fig, ax = plt.subplots(figsize=(6.5, 5))
sns.heatmap(corr, mask=mask, cmap="RdBu_r", vmin=-1, vmax=1, center=0,   # diverging, centred on 0
            annot=True, fmt=".2f", square=True, cbar_kws={"label": "correlation r"}, ax=ax)
ax.set_title("Correlation matrix")
plt.tight_layout()
plt.show()

6. Clustered Heatmaps

A clustered heatmap reorders both the rows and the columns of a data table by hierarchical clustering, so that similar rows and similar columns end up next to each other, and draws the clustering as tree diagrams (dendrograms) along the edges. Michael Eisen and colleagues made it the standard picture of gene-expression data in 1998, [5] and Leland Wilkinson and Michael Friendly traced its history back more than a century. [6] Seaborn draws one with clustermap:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

rng = np.random.default_rng(2)
genes = [f"gene{i:02d}" for i in range(30)]
samples = [f"S{j}" for j in range(12)]
# synthetic "expression" data: three groups of genes behave differently in two groups of samples
pattern = np.repeat([[2, -1], [-1.5, 1.5], [0, 0]], 10, axis=0)
group = np.repeat([0, 1], 6)
data = pattern[:, group] + rng.normal(0, 0.7, (30, 12))
order = rng.permutation(30)                                # shuffle rows so the pattern is hidden
df = pd.DataFrame(data[order], index=np.array(genes)[order], columns=samples)

g = sns.clustermap(df, cmap="RdBu_r", center=0, z_score=0,   # z_score=0: standardise each row
                   figsize=(7, 8), dendrogram_ratio=0.15, cbar_pos=(0.02, 0.85, 0.03, 0.12))
g.figure.suptitle("Clustered heatmap: rows and columns reordered by similarity", y=1.01)
plt.show()

Read a clustered heatmap from the tree inward: branches that join low down are very similar; branches that join only near the top are different. The order within a branch can be flipped without changing the tree, so the exact left-to-right sequence means less than it seems.

7. Normalise Before You Colour

When the columns of a table have different units or ranges, colouring the raw numbers lets the largest column take over the whole colour scale. Converting each column to z-scores (subtract the column mean, divide by its standard deviation) or rescaling it to 0–1 puts them on an equal footing.

8. Parallel Coordinates

In parallel coordinates, each variable gets its own vertical axis, the axes stand side by side, and each data point becomes a line that crosses every axis at its value. Maurice d’Ocagne described the idea in 1885 as a calculating aid, and Alfred Inselberg developed it as a way to visualise many dimensions in 1985. [7]

import pandas as pd
import matplotlib.pyplot as plt
from pandas.plotting import parallel_coordinates
from sklearn.datasets import load_iris

iris = load_iris(as_frame=True)
df = iris.frame.drop(columns="target")
df.columns = [c.replace(" (cm)", "") for c in df.columns]
scaled = (df - df.min()) / (df.max() - df.min())          # put every axis on 0–1
scaled["species"] = iris.target_names[iris.target]

fig, ax = plt.subplots(figsize=(8, 4.5))
parallel_coordinates(scaled, "species", color=["#0072B2", "#E69F00", "#009E73"], alpha=0.5, ax=ax)
ax.set_ylabel("Scaled value (0 = minimum, 1 = maximum)")
ax.set_title("Parallel coordinates: each line is one flower")
plt.tight_layout()
plt.show()

9. Radar Charts

A radar chart (spider chart, star plot) arranges the axes like the spokes of a wheel and joins each item’s values into a polygon. Star-shaped charts of this kind go back at least to Georg von Mayr in 1877. [8] Radar charts are eye-catching and popular for profiles, but they have real problems: the area of the polygon, which dominates the impression, depends on the order of the spokes, and values on spokes at different angles are hard to compare.

import numpy as np
import matplotlib.pyplot as plt

labels = ["Speed", "Battery", "Camera", "Storage", "Value", "Screen"]   # try reordering!
phone_a = [9, 5, 9, 8, 4, 6]                              # synthetic scores out of 10
phone_b = [6, 9, 6, 5, 7, 8]

angles = np.linspace(0, 2 * np.pi, len(labels), endpoint=False).tolist()
angles += angles[:1]                                      # close the polygon

fig, ax = plt.subplots(figsize=(5, 5), subplot_kw=dict(polar=True))
for scores, name, col in [(phone_a, "Phone A", "#0072B2"), (phone_b, "Phone B", "#D55E00")]:
    vals = scores + scores[:1]
    ax.plot(angles, vals, color=col, label=name)
    ax.fill(angles, vals, color=col, alpha=0.2)
ax.set_xticks(angles[:-1], labels)
ax.set_ylim(0, 10)
ax.legend(loc="upper right", bbox_to_anchor=(1.25, 1.1))
plt.tight_layout()
plt.show()

10. Small Multiples and Facets

Often the best way to show four or five variables is not one complex chart but many simple ones. Faceting splits a plot into small multiples (Part 2) by the values of one or two categorical variables, with colour for a third, while keeping the axes identical so that the panels can be compared. Seaborn’s relplot, catplot and displot do this with the col, row and hue arguments: [9]

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

rng = np.random.default_rng(3)
rows = []
for region in ["North", "South", "East", "West"]:
    for season in ["Winter", "Summer"]:
        temp = rng.uniform(0, 30, 40)
        slope = {"North": 2.0, "South": 3.5, "East": 2.5, "West": 1.0}[region]
        sales = 20 + slope * temp + (15 if season == "Summer" else 0) + rng.normal(0, 8, 40)
        rows += [{"region": region, "season": season, "temp": t, "sales": s} for t, s in zip(temp, sales)]
df = pd.DataFrame(rows)

# one panel per region (columns), colour by season: four variables in one figure
g = sns.relplot(data=df, x="temp", y="sales", hue="season", col="region", col_wrap=2,
                height=2.6, aspect=1.3, palette=["#0072B2", "#E69F00"], s=20)
g.set_axis_labels("Temperature (°C)", "Ice cream sales")
plt.show()

11. Common Misreadings

  • Reading exact values from colours. Colour is the least precise encoding; use heatmaps for patterns and label cells when numbers matter.
  • Seeing boundaries that a rainbow colour map created. Sharp colour changes may not be sharp changes in the data.
  • A diverging scale centred in the wrong place. The neutral colour should mean something, such as zero.
  • Comparing colours across separately scaled panels. Two heatmaps with their own colour bars cannot be compared cell for cell.
  • Over-reading the order of a clustered heatmap. Branches can be flipped; only the tree structure is meaningful.
  • Judging radar charts by area. The area depends on the order of the spokes.
  • Forgetting standardisation. After z-scoring, “high” means high relative to the others in that column, not high in absolute terms.

12. Legend and Record

Legend and Record: who invented the heatmap?

The legend: heatmaps were invented by genome scientists in the 1990s.

The record: clustered heatmaps became famous with gene-expression studies, but Leland Wilkinson and Michael Friendly traced shaded tables back to 1873, when Toussaint Loua coloured a table of social statistics for the twenty districts of Paris, and found reordered, shaded matrices in the work of statisticians and psychologists through the twentieth century. [6] The term “heat map” itself was trademarked in 1991 by a software developer for a display of financial market data.

A second record: in 1973 Herman Chernoff proposed representing each data point as a cartoon face, with variables mapped to features such as the size of the eyes, the curve of the mouth and the shape of the head, arguing that people are very good at reading faces. [10] Chernoff faces are memorable, but the impression depends heavily on which variable gets which feature, and they are rarely used today except as a lesson in how encodings shape what we see.
